# 🎮 Jogo da Velha em Java

Um projeto simples de **Jogo da Velha (Tic-Tac-Toe)** desenvolvido em **Java** para rodar no console.  
O objetivo foi praticar **lógica de programação** e **conceitos fundamentais** da linguagem.

---

## 🚀 Funcionalidades

- Tabuleiro 3x3 exibido no console.
- Dois jogadores (X e O) jogam alternadamente.
- Verificação de **vitória** nas linhas, colunas e diagonais.
- Verificação de **empate**.
- Tratamento de erros ao escolher posições inválidas.
- Encerramento automático quando há vencedor ou empate.

---

## 🛠️ Tecnologias utilizadas

- **Java (JDK 21)**
- Estruturas:
    - Matrizes bidimensionais (`char[][]`)
    - Estruturas condicionais (`if/else`)
    - Estruturas de repetição (`for`, `do/while`)
    - Tratamento de exceções (`try/catch`)
